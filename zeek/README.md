# Zeek

Zeek provides network security monitoring and rich connection metadata.

## Responsibilities

- Network connection analysis
- Protocol metadata
- Traffic logging
- Investigation context

## Key Evidence

The completed lab generated:

`conn.log`

This provides useful context for correlating network activity with Suricata alerts and endpoint telemetry.

## Investigation Value

Zeek helps answer what happened around an alert rather than only reporting that an alert occurred.
